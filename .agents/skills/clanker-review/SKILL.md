# Clanker Harness Review

Review pending improvement proposals generated by the weekly analysis pipeline.

## Process

1. Run `clanker review` to see all pending proposals
2. For each proposal, evaluate whether it would actually help
3. Accept proposals that have clear expected value
4. Reject proposals that are noise or low-impact
5. For accepted proposals, implement the change (add hook, update memory, create skill)
6. After implementation, the regression detection system will track whether it helped

## Available Commands

```bash
clanker review              # Interactive review of pending proposals
clanker analyze weekly      # Full weekly report with cost-weighted rankings
clanker analyze errors      # Top error-producing sessions
clanker analyze slow        # Longest sessions
clanker sessions --last 7   # Recent session metrics
clanker alert list          # Active alerts
clanker version             # Status overview
```
